# Spin Booth

A free web app for a 360 photo booth. Open it on the phone that goes on the spinner arm:

1. Pick a border (or upload your own PNG with a see-through middle).
2. Tap **Record a spin** or **Take a photo**.
3. Pick an effect: Normal, Slow-mo, Speed ramp or Boomerang.
4. Tap **Add border**, then **Save**.

Everything runs on the phone. Nothing is uploaded anywhere.

Live site: https://jaila-bison.github.io/spin-booth/
